# AI Atlas visual direction v3

Quality bar for the next UI generation:

- Strong coral navigation rail on desktop; compact mobile header.
- Nova is the product mascot and guide, not just a generic robot box.
- Main reading canvas stays clean, white, and content-first.
- Concept catalog is grouped into clear families with compact illustrated tiles.
- Every concept gets an original scene/metaphor, not recycled boxes and arrows.
- Illustrations use a limited flat-vector palette: coral, teal, gold, blue-gray, warm paper, dark ink.
- Lesson chapters progress from problem → metaphor → system → engineering → boundaries → teach-back.
- 3D is used only where interaction materially helps understanding (MCP flagship), not as the default visual language.
- Mobile keeps the same learning hierarchy with simplified art and stacked flows.
