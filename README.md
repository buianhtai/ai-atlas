# AI Atlas

A Feynman-style AI learning web app for understanding MCP, RAG, Agents, Multi-Agent systems, LangChain, LangGraph, and related concepts.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Import `buianhtai/ai-atlas` into Vercel.
2. Vercel should detect Next.js automatically.
3. Deploy with the default settings.

No database or environment variables are required for this MVP.
